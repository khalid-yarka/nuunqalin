JSON Format Guide

Required Fields

  • 📌 subject - Must exist in database
  • ❓ question - Question text
  • 🔘 options - Array of options (3-6)
  • ✅ correct - Index of correct option (1-based)
  • 📊 difficulty - 1 to 5

Optional Fields

  • 📖 chapter - Chapter name
  • 🏷️ tags - Array of tags
  • 💡 explanation - Answer explanation
📄 Example JSON:
{
    "metadata": {
        "subject": "Geography",
        "chapter": "Chapter 1: Introduction"
    },
    "questions": [
        {
            "tags": ["geography", "africa", "capitals"],
            "difficulty": 2,
            "question": "What is the capital of Somalia?",
            "options": ["Mogadishu", "Hargeisa", "Kismayo", "Garowe"],
            "correct": 1,
            "explanation": "Mogadishu has been the capital since 1960."
        }
    ]
}
